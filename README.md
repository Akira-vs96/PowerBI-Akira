# PowerBI-Akira

## USD/KZT және валюталық тәуекелдерді талдау

Жоба соңғы 20 жылдағы (2006-11–2026-10) USD/KZT бағамын, Brent бағасын және
BIS қатарын зерттейді. Таңдалған жалғыз әдіс — **Time Series**: курс датамен
реттелген үздіксіз уақыттық қатар, онда ұзақ мерзімді тренд, маусымдық әсер және
девальвациялық секірістер көрінеді. Бастапқы күнделікті қатарда уақыт бойынша
пропуск жоқ, сондықтан айлық динамиканы, стационарлықты, декомпозицияны және
болжауды бір әдістемелік тізбекпен талдау орынды.

## Іске қосу

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python analysis.py
```

Нәтижелер `output/` қалтасына UTF-8 CSV ретінде жазылады. Power BI-да ашу
бойынша қадамдар [powerbi_guide.md](powerbi_guide.md), қазақша қорытынды
[conclusions_kk.md](conclusions_kk.md) файлында.
